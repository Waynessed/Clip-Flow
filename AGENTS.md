# ClipFlow implementation rules

Read CLIPFLOW_HANDOFF.md, docs/current-state.md and docs/implementation-log.md before changing code. Preserve user changes. Keep the implementation log, walkthrough, decisions and current-state records aligned with actual code and executed evidence. Never report planned or simulated behaviour as verified. Explanations of CF steps must inspect the recorded revision and cite the actual functions and tests. Commit after verified stages; the current user explicitly authorizes development pushes to origin.
