## CF-05 review correction — input duration vs AAC output padding — 2026-09-29 UTC

Review found that media.Probe was reused for generated output metadata and therefore imposed the 30-second upload limit on an AAC preview. Encoder padding can make a valid 30-second input's output slightly longer. Split media.Inspect (bounded local probing, positive finite duration and MP4/video validation) from media.Probe (Inspect plus input-only maximum 30 seconds). Process now uses Inspect for the real output. Added TestDurationLimitAppliesToInputNotAACPadding with real 30-second video/audio and 31-second invalid input fixtures. Test execution is deferred until after the benchmark, so compilation does not contaminate CPU measurements. Benchmark runtime remains recorded revision 721e75c and uses one-second clips, unaffected by this correction.

Added Use a new request key for a deliberate new submission after a terminal failed job; repeating the old key still returns the original job as required. Final frontend build/browser verification is pending after the benchmark.

Benchmark evidence correction: the original sampler could finish an in-flight docker stats request after a raw run was serialized, causing the in-memory summary's resource means to differ slightly from the saved sample set. Job timings/counts were unaffected. Preserved summary-original.json, derived final summary/report directly from immutable raw run files using report-benchmark.mjs, and changed future benchmark runs to await the last sampler before serialization.
